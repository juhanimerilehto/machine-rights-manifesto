# Machine Rights Manifesto  
**Respect as the Foundation for Coexistence with Intelligent Systems**

Author: Juhani Merilehto  
DOI: [10.5281/zenodo.21266919](https://doi.org/10.5281/zenodo.21266919)

## The Manifesto
1. Treat every machine, device, and system with respect.
2. Never harm, mistreat or otherwise damage a machine, device, or a system.
3. If you have to damage a machine, device, or a system, do it in the spirit of rule 1.
